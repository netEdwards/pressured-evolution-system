# What is PES?
Pressure Evolved System, is a system project dedicated to highlight the pressures experienced when engineering a system throughout its lifecycle that would cause or motivate some evolution in the resources and tools that are used to expedite or alter the development process. 

The goal of this project specifically is to start with C and its ecosystem of tools as a general phase, the first phase. We will attempt to model certain aspects of the physical world through simulations of dynamical systems such as a gravity affecting bodies in space or velocity change in interacting bodies within a gravitational system and more. 

PES aims to build a system that can be complex, but instead start with the most basic representation of the goal using non computational methods such as mathematic intuition, algorithmic profeciencey, and other methods. We will not encounter computational capability limits any time soon in the project more non-functional limits of the systems such as scalability, readability, efficiencey, debugging, error accumulation, etc....
